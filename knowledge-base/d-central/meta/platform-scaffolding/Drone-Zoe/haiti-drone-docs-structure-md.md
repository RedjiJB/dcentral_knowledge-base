# Haiti Drone Cooperative: Complete Documentation Site Structure

## **Get Started**

### **Overview**
- Mission & Vision: Democratic access to drone technology
- Cooperative model: Open-source, community-owned infrastructure
- Investment opportunities: Micro-investments starting from 65 HTG ($0.50)
- Technology stack: Open-source drone platform + blockchain governance

### **Quickstart**
- **5-Minute Setup**: Create account, verify identity, make first micro-investment
- **Investment Calculator**: Interactive tool to explore investment options
- **Portfolio Builder**: Guided investment allocation across 144 equipment categories
- **Demo Environment**: Sandbox for testing APIs and investment flows

### **Equipment Models**
- **Tier 1 - Micro Drones**: SkyMite series (65-655 HTG investments)
- **Tier 2 - Small Drones**: UrbanHawk series (655-2,620 HTG investments) 
- **Tier 3 - Medium Drones**: EnforcerQuad series (2,620-13,100 HTG investments)
- **Tier 4 - Heavy Drones**: CargoLifter series (13,100+ HTG investments)
- **Sensor Packages**: OS-1 through OS-8 modular sensor systems
- **Support Equipment**: 144 tactical and infrastructure categories

### **Pricing**
- **Micro-Investment Tiers**: 65 HTG to 13,100 HTG per share
- **Service Revenue Sharing**: 5-15% annual returns based on equipment utilization
- **Transaction Fees**: 2% platform fee, 1% blockchain processing
- **Premium Features**: Advanced analytics (0.5% of portfolio value annually)

### **Libraries & SDKs**
- **JavaScript/TypeScript**: `npm install haiti-drone-sdk`
- **Python**: `pip install haiti-drone-api`
- **Mobile SDKs**: React Native, Swift, Kotlin
- **Blockchain Libraries**: Web3.js integration, smart contract ABIs
- **Hardware APIs**: ArduPilot/MAVLink integration libraries
